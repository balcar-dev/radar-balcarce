1. Para que se prenda lo ya armado (10 minutos)

Pegar la clave gratis de OpenRouter (respaldo de las IA)

Crear una clave (Create Key; no hace falta cargar plata) y pegarla en GitHub con el nombre OPENROUTER_API_KEY. Ya hay una guardada en la PC de ustedes: pueden usar esa misma.

Crear la variable FOTOS_MENORES_OFICIALES con el valor Si. Para apagarla, se borra.

Crear la cuenta de Bluesky

Nombre de usuario radarbalcarce (o el que esté libre). La bio y los tamaños de las imágenes están listos para copiar en la tabla de redes.

bsky.appPerfiles para copiar

Crear el bot de Telegram

Entrar a Telegram, buscar @BotFather, escribir /newbot y seguir los pasos. Después, crear un canal público @radarbalcarce y sumar el bot como administrador. El token que da BotFather se pega después en GitHub, no en un chat.

web.telegram.org

2. Para activar el archivo permanente de notas (antes del 2/11)

Sumarle permisos al token de Cloudflare

Editar el token que ya está (CLOUDFLARE_API_TOKEN) y agregar estos permisos: Zone → Workers Routes: Edit, Zone → Zone: Read, Account → Workers R2 Storage: Edit, Workers KV Storage: Edit, Workers Scripts: Edit y Cloudflare Pages: Edit. Guardar. No hay que volver a pegarlo en GitHub si se edita el mismo token.

Cloudflare: tokens

3. Para pasar el robot a Cloudflare (media hora, una vez)

Esto deja el repositorio principal en los 2.000 minutos gratis de GitHub, para poder pasarlo a privado sin pagar. Hasta que yo lo prenda, nada cambia.

Crear dos tokens de GitHub (grano fino)

Uno para el repositorio radarbalcarce/radar-balcarce con Contents: lectura y escritura y Actions: lectura y escritura, sin vencimiento: pegarlo como secreto RADAR_GITHUB_TOKEN. Otro para radarbalcarce/radar-balcarce-render con Contents: lectura y escritura: pegarlo como secreto RENDER_GITHUB_TOKEN.

GitHub: nuevo tokenGitHub: nuevo secreto

Crear la llave de R2 (dos valores)

En Cloudflare → R2 → Manage API tokens → Create API token con permiso Object Read & Write. Da dos valores: pegarlos como secretos R2_ACCESS_KEY_ID y R2_SECRET_ACCESS_KEY. Los depósitos radar-motor y radar-render los crea el proceso solo.

Cloudflare: llaves de R2

Crear la variable del render

Variable R2_RENDER con el valor radar-render.

GitHub: nueva variable
